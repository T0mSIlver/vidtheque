Run your own

Yours, on your box.

One compose file, one SQLite file, no build step, no runtime network dependency. It runs the CPU half on a Pi. MIT.

Start it
docker compose up -d

Clone, copy .env.example to .env, and point it at the builders you follow.

Point your agent at it
claude mcp add --transport http vidtheque <url>

Any agent can drink from it: one line to add the corpus to Claude, Codex, or anything else that speaks MCP.
